# Instructions for this wiki

*A starting brief, written by the agent that built this part and not by the owner. It is the owner's file: replace it with your own words. The OpenWiki tool is described as reading this file and not rewriting it.*

This wiki is for what is known about the data and methods the science factory in this repository works on: what each record is, how it was sampled, where it is unreliable, and the pitfalls that make a wrong answer look right. Keep one thing to a page and say it in the title.

Do not record findings here. A finding comes from a confirming study and a steward's signature. Do not mark a page as verified on a person's behalf.

Pages that agents draft from explorations wait in a queue outside this directory until a person accepts them.
